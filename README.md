## Compilation

Compile the project with **XeLaTeX** to generate the PDF.

## Origin

This project is based on the original [DTU thesis template](https://da.overleaf.com/latex/templates/dtu-thesis-template/dyxwwkhmzrbx). It has been simplified and adapted for regular assignments that do not have such strict design requirements.

## Project structure

- `Your_name-Assignment.tex` is the main entry point that assembles the complete document.
- `Frontmatter/` contains the front page and other content that appears before the main text.
- `Chapters/` contains the assignment chapters. Add, remove, or reorder chapters in the main `.tex` file.
- `Backmatter/` contains appendices and other content placed after the main text.
- `Setup/` contains the template configuration, including the preamble, document settings, and static definitions.
- `Pictures/` contains images and logos used by the document.
- `latex_compile/` contains generated compilation files and should not normally be edited manually.
